# Hospital Emergency Room Dashboard - Excel

An interactive monthly dashboard to analyze ER patient flow, wait time, and department referrals.

### 📊 Dashboard Preview
![Dashboard](Screenshot%202026-10-05%20001229.png)

### Key Features
- Month-wise & Year-wise Slicers
- KPIs: No. of Patients, Avg Wait Time, Satisfaction Score
- Gender, Age Group, Admission Status Analysis

### 🛠️ Tools Used
MS Excel | Pivot Tables | Slicers | Charts
